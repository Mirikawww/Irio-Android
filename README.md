# Irio Android

Irio 是一款 Android AI 对话客户端，可连接不同的模型服务，在对话中使用工具、处理附件和阅读结构化内容。

## 功能

- **模型与提供商**：支持 OpenAI、Anthropic、Gemini 等 API 协议，自定义服务地址与模型。
- **对话与阅读**：流式回复、消息编辑与回复重试，支持 Markdown、代码高亮、数学公式和 Mermaid 图表。
- **图片与语音**：发送图片和文件，使用兼容模型生成图片，支持语音输入与朗读。
- **工具与扩展**：网页搜索、记忆、MCP、子智能体及本地 Linux 沙盒。
- **数据与外观**：本地对话记录、数据导入导出、与 Windows 客户端局域网互连，以及主题和字体设置。

## 使用

需要 Android 13 或更高版本，并自行配置模型服务和 API 密钥。部分功能需要对应模型或额外服务支持，相关费用由服务提供商收取。

模型请求及所需上下文会发送至配置的服务；启用搜索或 MCP 等功能时，也会与相应服务通信。
